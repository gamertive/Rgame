# 🎯 Round Shooter 2.0

**Многопользовательский 2D шутер** с раундами, боссами, карточками улучшений, способностями и системой рангов.

![Node.js](https://img.shields.io/badge/Node.js-18+-green)
![Socket.io](https://img.shields.io/badge/Socket.io-4.7-blue)

## 🎮 Особенности

- 🌐 **Мультиплеер** — играй с друзьями в реальном времени
- 🔄 **Раунды по 8 минут** — напряжённые бои
- 👹 **Боссы** каждые 2 раунда с уникальными паттернами атак
- 🃏 **10 карточек улучшений** — урон, скорострельность, мультивыстрел, рикошет и др.
- ⚡ **3 способности** — рывок (Q), щит (E), граната (F)
- 🗺️ **4 уникальные карты** — меняются между раундами
- 🏆 **Система рангов** — от Bronze до Legend
- 🎵 **Синтезированные звуки** — без внешних файлов
- ⚙️ **Настройки** — громкость, чувствительность, частицы
